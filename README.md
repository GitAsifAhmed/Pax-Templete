# Pax Template

A responsive front-end website template built with HTML, CSS, and JavaScript.

## Overview
This project is a static demo site used to practice building clean, 
responsive layouts and translating a design into working front-end code.

## Built with
- HTML
- CSS
- JavaScript

## Getting started
Clone the repo and open `index.html` in a browser - no build step required.

```bash
git clone https://github.com/GitAsifAhmed/Pax-Templete.git
```
